# TODO

参考滴答清单的个人任务工作台。当前为早期 Web 原型，桌面优先布局，可离线使用（已加载页面时），浏览器本地持久化。

## 运行

需要 Node.js 20+。

```sh
npm install
npm run dev
npm test
npm run build
```

## 当前功能

任务创建、编辑、完成、删除撤销，清单、日期、优先级、备注、检查清单、智能视图、搜索、排序、重复任务（每日/周/月、保留或跳过过期）、深浅主题、JSON 导出。

当前未实现系统提醒、导入恢复、标签、拖拽、日历、SQLite、桌面安装包和云同步。浏览器数据清理会删除任务，请定期导出；JSON 导出暂不能通过界面直接恢复。

## 开发约定

早期快速迭代，允许直接提交 main，不强制 PR 或复杂 CI/CD。保留必要本地测试和构建，不绕过分支保护。使用中文提交信息。详见 AGENTS.md。
