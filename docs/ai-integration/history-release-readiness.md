## 安装准备（未授权安装）

1. 核对实际正式应用、bundle ID、版本、签名与已启动进程；只检查正式数据存在性和容量，不未经授权读取内容。
2. 另行明确授权后停止正式应用并备份原应用、完整SQLite文件及其必要WAL状态、必要WebView数据；验证备份和可恢复性，保护真实数据。
3. 从冻结候选生成正式bundle ID的本地安装候选，验证签名、旧数据兼容和降级限制，不用隔离QA二进制覆盖正式应用。
4. 由用户启动、确认工作空间和高级权限；以普通非敏感测试任务核验CLI、真人确认、撤回、重做、同步。全局CLI/共享Skill随真实候选兼容验收更新。
5. 真实双端、真人确认、正式安装、真实发行构建的万级性能仍未验收；高密度保存和历史读取明显偏慢，是后续性能专项，不宣称已满足正式发布门槛。重复系列及不可逆事实继续保护。未经授权不合并、不发布。
