## 二、最新生效的设计规则

- 当前八卡片：时间、提醒与计划；组织与状态；备注与标签；检查清单；子任务；关联任务；链接与附件；活动与系列历史。仅展开/折叠两档，旧摘要偏好迁移为折叠。

- 优先复用 SmartSelect / SearchSelect / EditableProperty / PropertyPopover / InfoTip；固定枚举使用普通选择，较大集合使用搜索。辅助说明用 i 图标；错误、必要风险和阻塞提示始终可见。
- 活动历史每任务最多300条、192 KiB，默认10条、每次展开20条；不能恢复已淘汰事件。备注仅保存长度摘要，不复制正文；附件仅记录操作，不记录文件名或内容。
- 智能番茄默认开启、扣除已保存专注默认开启、智能合并尾段最多5分钟；严格标准及均匀分配可选。连续计划默认关闭。计时目标在启动时锁定；自然到期结算，后续动态重规划。实际记录独立于计划。低于60秒默认不计入时长/次数/日志，关闭后允许有效正时长；已有记录不追溯删除。
- 本轮最终规则优先于 DESIGN.md 中历史阶段的三档、40条及固定番茄时长描述。
