# ActivityWatch 周期统计与真实元数据验收

基线 9165d5bfbbf4c02ec080d1eae865b6a257c27691，独立 feat/activity-tracking。自主采集 crate 与 ccd8c20 历史文档保持零差异，不恢复采集、消息队列、数据库，不接云，不修改 ActivityWatch 或正式用户数据。

## 实际服务元数据

本轮仅 GET http://127.0.0.1:5600/api/0/info 和 /api/0/buckets/；固定 IPv4 loopback、拒绝代理和重定向、限量响应，不请求 events/query。先用 Python 只输出结构汇总，再用项目实际 Provider 的 metadata_check example 独立复核。两次均成功：
- version v0.14.3（前缀 v 已由 Provider 兼容）。
- info 字段 device_id, hostname, profile, testing, version；仅保存字段名和版本，不保存身份值。
- 当前主机唯一 currentwindow、afkstatus 各1，web.tab.current 为0；另有1个非当前主机的数据桶，不自动归并，不打印其身份或事件。
- Rust 实际输出 {"version":"v0.14.3","app":true,"afk":true,"browsers":0}。有数据桶不是有完整有效活动；真实网站覆盖仍未知。
- 未授权具体历史日期及范围，故没有查询任何真实活动事件，未执行锁屏/休眠、实际浏览器切换或真实查询耗时实验。不强制改变用户工作会话；后续须明确授权日期/数据类型后再验收。metadata_check 仅检查元数据，不是桌面 IPC 运行验收。

## 周期 UI 和计算

日、自然周（周一开始）、自然月、自然年；支持上一/下一周期、今天、日期输入，未来区间裁剪到当前时间，闰日及本地 DST 23/25小时。明确显示所授权范围，切换日期/周期或离开页面立即清除结果，重新读取须用户主动授权。使用既有 Segmented、WorkspaceMetrics、Module Card 和双主题令牌，无新增前端依赖。
- 日视图：应用/网站彩色时间线，稳定主体颜色（8色有限调色板可能复用颜色），标签和列表辅助识别；软件/网站类型切换和主体筛选，排行点击筛选。保留原单日任务、专注、规划对照，不自动改写任务。
- 周/月按日，年按月汇总；缺失记录以未知空柱展示，部分覆盖只展示已确认时长；网站无可确认日期单列，不能推断为零。年度各月显示应用/AFK共同覆盖率而非网站覆盖率。点击日柱进入单日日期，必须重新授权（示例亦需主动打开）。排行与概览始终保留全范围总量，筛选仅影响趋势及时间线。示例与真实数据严格区分。
- 每日切片使用本地日期实际 UTC 边界；连续分段，每批最多7天，年度最多53批；单批按原只读 GET events 读取窗口/AFK/本机受支持浏览器，剪裁、交集和去重，再按日聚合，跨分段无重叠。仅单日请求返回详细时间线，趋势请求不返回原始时间线。不采用 flood 填补休眠等未知缺口。明确 focused=false 的网页记录与 private/incognito 排除；缺少标记时仍不能判断隐私或真实焦点。
- 取消/离开后不再发后续分段，忽略已发请求结果；原生已发请求可能继续至超时，并非强制取消 HTTP。当前页面阻止重复并发请求，未实现跨窗口/重挂载全局锁。任何分段失败、缺失或总量校验错误均拒绝发布部分汇总；每流每批2万事件、单响应8MiB、汇总每批2万分类行、全范围10万分类行/2000主体限制；超限提示缩小范围，不静默截断。每个 HTTP 请求5秒超时；全年较慢或超限时应缩小范围，不承诺固定性能。无持久缓存、无采集器、无同步。
