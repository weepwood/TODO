# TODO V1.3–V1.5 功能深化路线

基线：现有任务、清单、智能筛选、重复规则、提醒、日历、规划、专注、习惯、统计、积分、同步与备份；不重复实现已有功能。方向为任务生命周期、时间管理、回顾与工作流联动，而非一味增加入口。以下为规划，未实现部分不得视为交付。

## V1.3 优先完成任务操作闭环
- 已完成显示：全局默认（兼容旧行为，默认关闭）、普通清单独立继承/显示/隐藏、底部独立可折叠历史区、详情或行复选按钮直接取消完成。本机偏好不写业务模型，不改变智能清单、日历及待办计数口径。
- 历史记录筛选：完成日期（今天/本周/本月/全部）、清单、标签；完成时间排序；待办和历史计数分别显示。
- 任务操作：置顶（独立于优先级）、快捷延期、保留任务预计时长的批量改期、快捷完成/撤销入口；复用现有历史与提醒机制，明确重复实例的撤销边界。
- 清单默认值：新任务默认优先级、预计时长、提醒、默认分组；不 retroactively 修改旧任务。
- 重复任务管理：系列视图、下次实例预览、单次与后续规则区分、暂停和恢复的明确语义。先做领域模型测试，避免重复生成、积分双计及历史损坏。

## V1.4 时间管理与任务复盘
- 分离计划执行日期与截止日期；新增字段必须先处理 SQLite/同步/备份兼容，旧数据不自动重解释。提供截止倒计时、过期预警。
- 今日建议：本地可解释规则识别拖延、过期、长期未安排、等待依赖及当日可执行任务；建议而不自动修改。
- 每日收尾/每周回顾：已完成、未完成、计划与实际专注时长、时间冲突、净积分；可选择延期或重新安排，输出 Markdown 摘要。
- 专注与任务联动：任务详情开始专注，完成时显示实际投入，估计与实际并列；不以计时完成自动认定任务完成。
- 清单归档、可选收藏/置顶、模板参数（日期与检查项）；归档不等于删除或完成。

## V1.5 个性化与工作流
- 保存视图：每清单独立过滤、显示字段、密度、排序和分组；在现有视图偏好上扩展。
- 活动时间线：状态、日期、清单、积分关键变化及操作来源，采用有界记录、明示本机或同步范围；不冒充完整不可篡改审计。
- 习惯与计划联动：可选择将习惯列入今日规划，不强制生成独立任务或重复计分；长期趋势及目标达成分析。
- 导入/导出与集成：可复用的 CSV/Markdown 任务清单，校验预览与去重；现有备份机制仍为完整恢复依据。
- 大规模任务：对历史列表、分组和搜索持续验证千/万级性能；避免同步冲突及长时间资源增长。

## 本轮交付：任务操作与回顾
- 普通待办置顶按本机账号视图偏好存储（最多300项）；各分组内优先显示，保留原排序，跨置顶边界拖拽不重排；不改变优先级，不同步置顶，不继承至新重复实例。
- 快捷延期一天/一周基于计划日期与今天中较晚者；原有今天/明天入口保留。计划时刻、预计时长、积分及独立提醒不变，沿用原重复锚点更新逻辑。
- 单次普通任务完成后6秒内可撤销，核对完成时间和当前状态，恢复原进行中/待处理阶段；拒绝过期回执、重复实例及已完成依赖任务。重复系列不提供快捷撤销，保留既有历史保护与全局撤销机制。
- 已完成历史增加今天/本周/本月/全部及清单筛选，手动排序默认最近完成优先；显示实际完成日期，原计划日期仍保留在详情。
- 统计→任务回顾：每日及周一开始的自然周，当周截至今天，支持日期选择、前后周期、Markdown实际下载、未完成任务及积压安排明天、跳转任务。计划、积压、冲突基于当前数据，不是历史快照；积分按完成日期推导，专注按开始日期归属，习惯按有效日期去重；报告不修改数据。界面每组至多100条，导出包含全部。
- 批量延期、历史标签和自定义日期范围、同步置顶、回顾快照等仍为后续工作，不宣称已经交付。

## 本轮交付：清单默认属性、相对延期及专注关联
- 清单默认预计时长、优先级、积分、计划日期及分组：本机账号独立保存；普通快速录入、全局新建及分组内新建复用默认值，显式日期/优先级/积分和指定分组优先，历史任务、模板及子任务不批量改写。默认提醒、显示字段及跨设备偏好同步仍待实施。
- 批量延期1/3/7天：按每项原计划日期移动，预览新旧日期、任务间重叠数量及跳过数量；只处理有计划日期的非系列普通待办，保留独立提醒、时刻、时长、积分；应用时核对原日期、时刻及预计时长，避免覆盖过期预览。外部日历冲突不计入此次预览。
- 任务详情显示已保存的当前实例专注次数与实际分钟数，排除休息记录；不自动完成任务，不合并系列历史，不包含运行中的尚未保存计时。

## 本轮交付：重复系列总览、任务建议与每日收尾
- 任务详情活动与系列历史新增系列总览，按真实实例统计待办、完成、跳过及历史；复用 nextOccurrence/advanceOccurrence 预测当前活动实例完成后的下一日期及序号，遵循结束日期/次数和已存在实例保护。完成后重复以今天完成为假设；多活动实例不预测；不提前生成，不修改旧记录。点击现有实例跳转对应普通或历史清单，删除记录只展示。暂停、恢复及独立系列生命周期仍需同步兼容设计，不以关闭重复冒充暂停。
- 今天清单新增任务建议，基于过期日期、至少7天未安排、已完成依赖和未完成依赖分类；同一任务可能出现在多个分类。显式点击才安排今天，重复实例不参与建议快捷改期；不采集额外行为，不接入AI。
- 统计回顾中的今日每日收尾：选择今天及更早有日期的普通待办、明确确认后统一安排明天，排除重复系列、无日期和历史；应用时校验当前日期、时刻、时长及状态，保留独立提醒、积分及专注记录。区别于按原计划相对延期；每组界面显示上限明确。

## 本轮增量：专注、收藏清单与模板
- 任务详情时间计划区在展示/编辑态均提供实际时长、次数、预计/实际对比和差额；前往专注预绑定当前普通待办，预计时长限制在现有1–180分钟范围，用户主动开始。已有计时则查看原计时，禁止覆盖或修改绑定。不自动完成任务。
- 收藏普通清单保存于本机账号偏好，侧栏收藏区只展示一次，保留原文件夹关系及清单数据；取消收藏恢复原导航位置。尚不支持归档、跨设备同步或独立字段显示。
- 模板创建先配置标题、目标清单、计划日期；显式确认才新建，保留模板内容、预计时长、优先级、合法积分、有效标签，重置检查项及任务ID，计划日期存在时才继承有效计划时刻；不继承历史、重复、独立提醒、附件、父子关系和依赖。默认提醒与高级日期偏移待后续。

## 本轮增量：导航归档、默认提醒、历史筛选与回顾快照
- 本机清单归档仅整理侧栏，归档项集中进入可折叠区域，可恢复且保留收藏和文件夹归属；不移动、不隐藏全局计划任务、不停止提醒，不是服务端业务归档。收集箱不可归档。
- 清单默认提醒时间仅在新建普通任务具有有效计划日期且提醒时间严格晚于当前时间时应用，录入预览明确提示未应用原因。旧任务、模板与重复系列不追溯修改，延期仍保留独立提醒语义。
- 已完成历史新增自定义起止日期、标签与清单组合筛选；日期按本地实际完成日期且含边界，可单边筛选，逆序日期显示提示并返回空集。
- 每日/周回顾支持主动保存本机只读Markdown快照、重新打开、下载及确认删除。每账号最多30份、总2MiB，不自动淘汰，不覆盖损坏存储；快照冻结保存时的重算报告，不是原计划历史事件记录，不与云端同步或工作空间备份合并。跨设备归档及快照同步、历史快照对比仍待设计。

## 本轮增量：回顾可视化、任务自动化与重复系列管理
- 实时每日/每周回顾增加完成数量、专注分钟、净积分的逐日趋势，以及上一可比周期六项指标差额；当前周与上一周相同天数比较。正负积分独立标识，专注每日取整。新版快照冻结指标与趋势，允许同周期长度的已保存报告比较，复用安全Markdown阅读渲染，原文可切换及按原样导出。旧版快照仍可读取，不回填虚构历史数据。
- 今天工作区与命令面板增加本机自动化规则管理，最多20条，支持清单范围、过期/无日期/今天条件、安排今天/明天/高优先级操作、启停、排序、预览、确认执行。基于同一输入任务集合计算，不级联；同一字段首个有效变更优先；仅普通待办，保留提醒、积分及历史，应用时复核预览。规则默认关闭自动执行；显式启用保存后，本机访客在打开/进入前台或日期变化时尝试每日运行，先保存当日回执再写任务，避免同日刷新重复，非后台调度。云账号仅手动执行；跨设备规则、服务端调度、多窗口原子锁及审计日志仍待后续。
- 重复系列提供暂停、恢复与结束。暂停仅允许单一合法活动实例且不存在后续实例；保留原次数和过期策略于可选seriesHold字段，将现有次数上限限制为当前序号并保留过期实例，兼容旧引擎的生成限制。新版暂停期间不可完成或自动跳过，原提醒继续；恢复还原原规则，可能按原跳过策略补进；结束保留当前实例并在完成后不再生成。历史不批量重写。混合旧客户端主动改规则或完成暂停任务、真实跨端往返尚未验收；发现围栏不一致不自动覆盖。任务增量和迁移保留新字段，结构性并发拒绝自动合并。
