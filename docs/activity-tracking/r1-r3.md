## R2 · 状态与时间边界

独立 Rust crate src-tauri/activity-core：活动、空闲、锁屏、休眠、未知、关闭、排除七态；半开区间 [start,end)。输入包含墙上时钟与单调时钟，两者差值偏离阈值时不生成虚假区间；回拨低于已提交水位时拒绝计时直至重新锚定；不跨进程重启补造活动；过长心跳间隔整段保守标为 unknown。当前观测区间为以前一采样状态近似，不代表精确系统事件时间。真实采集器需要区分明确事件边界与采样推断，按来源记录质量，并把时钟异常/缺口作为覆盖率指标单独持久化。

active 仅接受有限 ASCII 标识；不是完整的域名或敏感应用分类验证。R4 需要真正的 URL 规范化、隐私模式识别、用户排除规则及权限检查。原生事件适配、输入空闲阈值、唤醒/锁屏、会话切换以及时钟异常实际观测均未完成。默认不启用采集。

网站聚合以同一设备同一浏览器的前台有效区间与浏览器活动区间求交；单设备单流的非重叠条件明确，防止网站和应用时间重复计入总量。多个浏览器或配置文件的联合去重尚待适配。

## R3 · 存储

独立 SQLite 文件、application_id 和 user_version 拒绝误传非活动数据库及未知版本；WAL、FULL synchronous、IMMEDIATE 事务。设备+数据流+起点主键，重复完全一致无操作，冲突或交叠拒绝整个批次；并发写入只允许一个重叠区间成功。现有 TODO SQLite 与 JSON 存储不改动。相邻同态区间可在批内合并，已提交边界不修改；日汇总按调用方提供的 UTC 起止裁剪，未来由时区层生成本地日界。暂未实现持久队列、进程崩溃故障注入、保留与删除、设备/账号绑定、文件权限、聚合缓存或迁移；调用方不得将原始活动跨账号共享。

## 可复现命令

在 crate 目录使用：
- cargo +stable test --offline --locked
- cargo +stable run --offline --locked --example synthetic
- swiftc probes/macos.swift -o /独立临时目录/macos-probe（仅执行该有界诊断，不安装）

本机 Rust 1.100.0、Swift 6.4.2、arm64；现有 rusqlite 0.37 bundled，锁定 crate 依赖。Rustfmt 组件缺失，未安装或改变全局工具链；格式检查未完成。

实测12/12测试通过，含100组固定种子独立逐毫秒（离散时间单元）区间对照、事务回滚、重启、跨日裁剪、并发重叠拒绝、非活动数据库字节不变。90日合成夹具每日8小时、每5秒模拟观测、每分钟更换状态，43,289条合并区间（含89条跨日失联unknown），预期有效时间1,296,000,000ms与实际完全一致。SQLite关闭后3,698,688字节；含状态处理、批内合并、导入和幂等重放耗时1594ms，单次聚合36747us（debug构建、单次本机样本，不代表生产性能或实际日常活动分布）。合成数据库已清理；日志位于 /Volumes/data/AI-Development/artifacts/todo-activity-r1-r3。未测真实采集资源、功耗与系统准确性。
