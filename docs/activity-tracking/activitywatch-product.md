# ActivityWatch 产品深化：分类、图表及规划回顾

基线 7dd098598a58830df202519167dd5462f8fa47c9，独立 feat/activity-tracking。读取上一批桌面验收报告和 AGENTS，遵守外部 ActivityWatch 只读、按日期主动授权、网站独立授权、不持久化历史、不上传数据的边界。本轮不请求真实 ActivityWatch 服务（包括元数据），不安装扩展、不修改权限/配置、不恢复自研采集，无 Rust/IPC/存储协议或依赖变更。

## 分类与关联
新增 activitywatch-analysis.js 和按需加载的 ActivityWatchAnalysis.jsx，复用现有 Module Card、Segmented、Lucide、Design Tokens。默认开发/学习/沟通/娱乐分类，真实模式默认无映射；自定义添加、重命名、删除，未分类保留。规则在已读取报告内编辑，主体从所选报告和已有映射选择；精确匹配软件名或域名，每主体至多一个分类和一个任务。可关联现有任务、解除规则；删除分类保留独立任务关联，删除任务不把其规则自动关联给其他任务。分类24项、映射500项上限，拒绝重复和含路径的主体。当前不支持通配、自动分类或批量导入。

显式保存仅将分类名/ID和用户明确选择的主体/分类/任务ID保存到独立 localStorage key todo-activity-rules-v1:账号scope（账号/guest 分离），不写业务 data、任务记录、同步快照或活动报告。配置不是加密存储，同源脚本/本机访问者仍可能访问；主体名和任务ID属于用户主动保存的敏感配置。损坏配置不自动覆盖；只有用户显式保存新规则才替换。修改即时预览，未保存离开/日期切换丢弃。示例数据及规则完全独立且仅内存，示例确认不落盘；真实规则不读取到示例。无跨设备同步，断开清理报告但保留显式保存规则。

## 图表与统计
分类堆叠按日/按月（年度）汇总，软件与网站独立视角，未分类单列，主体不重复计算。缺失日期以虚线表示，不作为零计入可用日；部分覆盖只反映已观测时长。单日按实际经过小时切片，DST 重复时段保留独立区间；小时没有已识别活动时无法区分空闲/缺失。多日使用已聚合日期热力图、按星期的可用日均值；不下载多日详细事件，不推断跨日小时规律。色板为有限稳定颜色，名称和时长辅助识别；热力图强度按当前报告相对最大值，不跨报告比较颜色。

上一自然周期需独立点击授权，沿用当前网站范围，不自动查询。只请求显示范围的现有七日分段，取消/离开停止后续分段，已发请求可继续至超时；失败不显示部分汇总。展示本期/上期时长、查询长度及应用/AFK覆盖率；只有等长且完全覆盖的软件数据才给出可比时长差，否则仅显示已识别差（不能解释为真实变化）；网站覆盖未知，不计算可比差。无持久缓存。

## 规划与回顾
单日保留原预计、日内规划、专注、规划/专注与活动交集，新增用户明确映射的活动时长与专注/匹配活动相对于规划的差。每任务的软件及网站匹配区间取并集，避免浏览器与网站重复计时；不同任务之间仍可重叠，不能相加。未匹配或缺乏数据不显示推断的任务耗时；偏差仅在有正时长和规划时展示，匹配差不是实际耗时偏差。预计为整体当前估计，规划是当前任务字段，专注区间仍是起点+记账秒数近似，不自动写回、重排计划或生成历史快照。真实报告提供打开当日回顾入口，使用已有 ReviewPage 日期导航；不会把活动数据复制到回顾存储。示例使用独立虚构任务，不跳到真实回顾。多日精确任务匹配暂不支持（保留轻量汇总）。
