# TODO

参考滴答清单的个人任务与时间管理工作台。当前版本 V0.6.0，桌面优先 Web 应用，浏览器本地存储。

## 本地运行

Node.js 20+。

```sh
npm ci
npm run dev
npm test
npm run build
npm run test:e2e
```

E2E 默认使用已安装的 Microsoft Edge（可通过 TODO_BROWSER_CHANNEL 设置已安装的浏览器）。

## 当前功能

- 任务、清单、文件夹、分组、标签、排序、多选批量修改、拖拽、回收站、模板、历史、全局搜索。
- 按天/周/月重复、自定义间隔、完成后重复、跳过过期、自定义重置时间、独立提醒、系列记录。
- 模块导航、可关闭详情、双主题、命令面板、快捷键、右键菜单、响应式布局。
- 月/周/日历、看板、四象限、每日规划与时间轴。
- 番茄钟、正向计时、休息、任务绑定、专注历史、每日习惯打卡、趋势及热力图。
- JSON 导入导出、v1 迁移、校验、自动/手动备份、异常恢复。

## 已知限制

Web 原型尚无 SQLite、原生安装包、后台系统提醒、云同步。页面关闭后不能保证提醒；清除浏览器数据会删除本地数据及备份。日期控件使用浏览器原生实现，尚未建立完整设计视觉基线。重复任务与模板能力见 AGENTS.md。

## 开发约定

允许普通功能直接提交 main，中文 Git commit；不强制 PR、Release 或复杂 CI/CD。集中开发、必要测试与构建、持续更新 AGENTS.md。

## V0.3.0 云端账号与同步

已连接独立 Supabase TODO 项目（东京）。默认公开客户端配置可直接运行，替换实例时使用 .env.example 中变量；不要向客户端提供服务端密钥。未登录仍使用原访客空间。打开设置 → 账号与云同步，注册并确认邮箱后登录；需要迁移本机数据时，选择“导入访客数据”并确认。导入会替换当前账号空间，建议先导出备份。

云端保存版本化完整工作空间，非逐任务实时同步。编辑后自动同步、联网恢复及定期轮询；检测到双方修改后停止同步并提示选择，保留冲突备份。暂不支持跨设备字段级自动合并。浏览器清除数据会删除离线缓存和本地备份；请定期导出。原生桌面后台提醒仍未实现。

数据库迁移见 supabase/migrations。新建实例时需应用迁移，并配置 Auth 的 Site URL、Redirect URLs 与确认邮件设置。当前线上项目已应用该迁移；不要重复执行。浏览器本地测试使用模拟 API，数据库 RLS 使用真实 PostgreSQL 测试。

## V0.4.0 桌面应用与演示站

演示站：https://weepwood.github.io/TODO/（由 Pages 工作流部署）。

```sh
npm ci
npm run dev
npm run desktop:dev
npm run desktop:build
```

桌面需要 Rust 1.90+ 和对应系统编译工具。Windows x64 NSIS 与 macOS Apple Silicon DMG 可通过 Actions 的「桌面安装包（手动）」获取构建产物；预览包不保证商业签名或 Apple 公证。关闭原生窗口隐藏到托盘，托盘菜单可退出。Cmd/Ctrl+Shift+A 唤起快速录入（系统占用时可能注册失败）。SQLite 作为按账号隔离的快照镜像，Web 缓存和现有 Supabase 同步保留。

新版支持指定星期/工作日、重复次数与截止、多提醒、父子任务、依赖、范围多选、撤销重做、快捷录入、ICS、时间冲突、统计筛选及虚拟列表。具体边界见 AGENTS.md。Pages 登录确认邮件需在 Supabase Auth 中配置生产 Site URL 与 Redirect URLs。

### V0.4.1

桌面工作空间及同步元数据使用 SQLite 主存储（Web 端保留 LocalStorage，使用 IndexedDB 保存同步基线）。首次升级保留旧 WebView 数据，旧镜像不一致时提供完整副本导出。普通独立任务的安全并发修改自动合并，真正冲突仍由用户决定；云端仍采用版本化快照。正式使用前请备份重要数据。

### V0.4.2

新增任务差量上传、云端版本探测和 Realtime 版本通知；完整快照仍兼容。桌面设置提供 SQLite 备份历史，搜索使用原生全文索引。专注周期可自动继续；外部日历支持本机保存 HTTPS 订阅及定期刷新（受 CORS/CSP 限制），链接不进入同步快照，但日程内容会同步。升级 FullCalendar v7 完整主题并修复日历渲染。数据库迁移已在默认项目应用，其他实例需同步迁移文件；旧实例缺少 RPC 时回退完整上传。

### V0.5.0 产品体验

新增智能清单、快速新建弹窗、基础 Markdown 备注、HTTP(S) 关联链接、活动摘要、工作时段规划与批量建议、同步日志和冲突比较。Web 生产版本支持 PWA 安装清单和离线应用壳，首次在线加载后可离线重载并继续编辑访客任务。智能清单、同步日志、订阅地址仅本机保存；重要任务仍建议定期导出。桌面新增窗口尺寸恢复、托盘快速录入和测试通知。安装包尚未商业签名或公证，真实账号认证及原生运行验收仍待完成。

### V0.5.1

支持可调整面板、CommonMark/GFM 备注预览、本机二进制附件、AND/OR 智能清单及工作空间同步、普通任务字段级冲突合并。旧智能清单保留本机副本；可显式迁移。附件使用 IndexedDB，限每文件 10 MiB、每任务 20 个、每账号 50 MiB，不纳入 JSON/SQLite 备份或云同步，请单独下载重要文件。字段合并保留双方原始备份。无新增 Supabase 服务费用。

### V0.6.0

新增连续任务差量下载（最多 8 个版本），与差量上传及完整快照兼容；默认 Supabase 项目已应用迁移，其他项目需运行对应 SQL。附件管理支持独立归档与 SHA-256 校验恢复；文件仅本机，归档未加密，重复导入会追加副本，工作空间与附件需分别备份。每日规划支持自定义工作时段、跨日延续、外部日程冲突检查。

### V0.6.1

每日规划新增比例时间块与重叠分列、15 分钟拖动吸附；备注支持展开 Markdown 编辑与安全实时预览。设置中可导出完整工作空间和附件归档，SHA-256 校验后分步恢复（任务替换、附件追加），归档未加密。没有新增云服务费用。
