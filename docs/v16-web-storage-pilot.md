# V1.6 Web 存储试验与正式切换门禁

日期：2026-11-26；基线：ecd536f。业务冻结，不直接迁移真实工作空间。

## 1. 方案及边界

上一阶段隔离真实浏览器实测 localStorage 的 10000 个默认完整字段任务无法首次写入，WebKit 的 4000 项完整备份也可能失败。采用浏览器原生 IndexedDB 事务（不加第三方依赖），复用现有原生 SQLite 的同步读取内存镜像/异步快照提交接口；不是把原生 SQLite 改成 IndexedDB。

试验仅在同时满足 VITE_TODO_IDB_PILOT=1、非原生、127.0.0.1:4178、会话标记 todo-idb-pilot=synthetic-only 时加载。Playwright 使用隔离浏览器 context 和合成夹具，禁止真实账号登录，禁用测试 service worker。普通开发服务 4197 和普通生产构建不启用，普通构建应无试验数据库 chunk。不能将会话标记用于真实数据迁移。本轮不提供公开激活入口。开发时运行：

```sh
# 遵守本机 resource-budget，使用隔离的 4178 测试服务器。
# TODO_BROWSER_ENGINE 可选 chromium / firefox / webkit。
TODO_IDB_PILOT=1 node node_modules/playwright/cli.js test e2e/ui-idb-pilot.spec.js --workers=1
```

## 2. 数据和事务

数据库 todo-web-workspace-pilot-v1，单对象仓 workspaces，固定 guest 记录。记录包含 scope、revision、mode、source（原始主数据/备份等允许键的精确字符串副本）、values（当前主数据/备份/元数据）。迁移先读原始数据，再校验主数据结构及允许键，事务内读取已有记录、若不存在则原子 add。原始 localStorage 完全保留，不覆盖、不删除。不允许主数据缺失但有备份的情况下创建空记录；原始损坏拒绝迁移。重复打开返回已有记录；原始工作空间改变则 fail closed；写入前再次核对原始键。没有云账号作用域迁移，其他本机偏好/附件索引/工作流等仍遵循现有存储。

写入前校验主数据，事务内检查 scope/mode/revision，单次 put 更新全部键；完成事件之后才更新已提交版本。使用 strict durability 提示，旧实现不支持选项时退回默认事务选项；不保证断电或异常浏览器关闭。请求错误/中止/配额异常不提交；复用内存镜像、flush、retry、pending/error 状态。并发旧版本拒绝覆盖，保留待保存内容供导出。数据库版本变化时关闭连接，升级阻塞时明确失败。浏览器仍可能回收非持久化 origin 数据，配额依引擎、磁盘与用户设置变化。

## 3. 迁移和回滚协议

- 初始迁移：原始数据 -> 校验 -> 单事务提交 -> 读取已提交记录 -> 工作台挂载。
- 迁移失败：不启动空工作台，不写原始存储；恢复页支持导出可读取的 IndexedDB 记录及原始数据。
- 普通保存：在内存镜像中合并主数据与备份写入，异步提交完整记录；未完成/未提交/错误时禁止静默离开（浏览器确认受浏览器策略限制）。事务失败可以导出当前内存数据或重试，不把导出当成保存。
- 无损回退：rollbackPilot 仅在 revision 精确匹配、模式 active、原始键未改变且当前全部键和原始数据完全一致时标记 retired；不删除 IDB 记录，不写 legacy；再次进入试验拒绝自动创建。当前实现为底层事务 API，尚未开放真实用户的回退 UI。
- 有修改/超配额：不允许直接切回 localStorage，先导出并由用户明确选择恢复目的地；大文件不能保证原存储可容纳。正式切换必须提供可核验的恢复文件、导入验证和防止旧客户端回退的控制。

## 4. 正式启用前仍需完成

1. 生产级独立迁移/恢复 UI，显式用户选择、迁移前后记录数量及摘要对照、双向备份导入验证、恢复部分不可读数据；避免通过清除标志来绕过已迁移版本。
2. 账号作用域、云同步事务与异步提交顺序、冲突备份、云端 3.5 MB 上限（与本机存储独立）、跨标签页及旧 PWA/SW 版本协调。未实测云账号，不能宣称已支持万级云同步。
3. 大型数据按记录或分片增量提交、独立长期内存/写放大和浏览器清理策略；当前仍为完整快照，解析、校验、备份与写入可能产生 O(n) 成本。其他本机工具仍有 localStorage 配额风险。
4. 真实物理设备、异常关机和浏览器关闭、磁盘不足、私密模式、持久化授权、升级阻塞、正式 CI 与独立 QA。冻结原始用户工作空间；不自动删除备份或迁移真实数据。

## 6. 第二代分片与迁移管理试验（2026-11-26，基线baed0fd）

第二代独立数据库 todo-web-workspace-pilot-v2，仅显式合成会话标志 synthetic-v2、VITE_TODO_IDB_PILOT=1、127.0.0.1:4178 非原生环境启用；不自动转换第一代数据库。迁移界面先确认原始键摘要，再事务复制。独立试验标志 todo-shard-pilot-guard 保证同一试验构建清除会话标志后仍进入管理页；只在显式试验迁移时写入，非业务原始键。普通构建和4197不启用，无法约束已经发布的旧客户端/PWA；真正切换仍需部署协议和旧版本拒绝写入机制。

任务ID稳定映射至128桶，任务顺序独立记录，元数据和备份按键分片。版本头记录分片及原始键SHA-256，打开时独立读取并校验所有分片和索引。提交先计算变化分片及摘要，再在同一事务中核对版本、旧源并更新分片和版本头；备份恢复在同一跨对象仓事务归档恢复前快照（含摘要）。恢复文件核对格式、作用域、数量、内容摘要，摘要是完整性校验而非身份认证或数字签名。损坏时禁止创建新记录覆盖，允许原始记录及旧源导出。无损回退界面仅当全部当前键与原始键语义一致才将记录标记retired；有修改必须先导出并人工恢复，不能强制回退。恢复归档未自动清理，正式版本需有明确保留、配额及导出策略。合成账号作用域通过复合键隔离，Web Locks防止同一访客空间多标签同时打开；真实账号仍不启用新存储。

万级完整默认字段主快照5678383字节，单任务正文43157字节、版本头10240字节，共53397字节/2条put，逻辑正文约减少99.06%；不等于SSD物理写入、浏览器日志或定期完整备份开销。单次提交30.9/25/57ms（Chromium/WebKit/Firefox），三引擎最终各5/5。整份工作空间仍需JSON解析、校验、分片生成、序列化，备份仍为完整键。持续会话采样暴露splitSnapshot及saveState为主要分配来源；保留原有30步撤销语义，不以减少功能伪造内存改善。下一阶段应研究按记录的dirty tracking、分片复用、快照序列化延迟和归档成本；正式真实数据迁移仍禁止。

账号同步增加异步提交前检查镜像与当前UI快照、flush后再次验证是否过期；云请求及本机元数据确认之间等待异步存储提交成功。既有云端3.5MB UTF-8上限不变，模拟API双设备冲突通过；真实云账号、原生异步同步和PWA升级切换仍需独立验收。

## 7. 增量计算、切换围栏与归档预算（2026-11-26，基线5fdd552）

试验正常编辑使用状态提交队列直接接收不可变工作空间对象，按任务ID分桶、成员引用和顺序识别变化；热身后未变化分片复用字符串，主JSON按需生成（完整备份到期、导出、兼容getItem），继续全量领域校验及关系检查。外部导入走完整验证，不复用外部对象的历史引用；异步提交失败保留草稿且重试仍基于上次已提交分片。万级单任务修改三引擎均127桶复用、1桶重算、0次主JSON序列化，最终分片与完整重算oracle一致。逻辑分片40724字节、头10337字节（本批夹具主5658383字节），时间22.6/15/28ms（Chromium/WebKit/Firefox单次）。全量任务遍历、领域校验、分组排序、元数据与完整备份仍有成本，依赖应用不可变更新契约，不能宣称所有路径O(1)。

恢复归档最多5份、逻辑JSON总量128MiB、单恢复文件64MiB。达到容量不自动删除，而是事务拒绝新恢复；可导出指定版本，再导入外部验证文件，确认与指定归档摘要及内容匹配后明确删除单条本地归档。删除与恢复均保留原始业务数据。独立恢复目标可选择当前隔离工作空间或仅生成可移植文件，不能直接覆盖其他账号、真实源或localStorage。归档预算为逻辑正文而非磁盘配额保证；用户仍需保管外部备份。

切换标志协议1，preparing→active→retired 单向，绑定原始键SHA-256；中断后以验证数据库状态核对，拒绝未知协议、错误源、缺失数据库或不兼容PWA。现有第一代试验写入器也检查切换标志；第二代写入事务检查active标志及工作线程控制器未变化。普通SW明确声明legacy协议，实际离线回归通过；模拟未知/等待中工作线程拒绝。普通构建（即使VITE_TODO_IDB_PILOT=1）强制DEV门禁并排除试验代码，4197不启用。已经发布的旧生产客户端无法被追溯约束；正式切换必须先分阶段发布兼容写入器、处理旧SW及所有活动客户端，真实跨版本部署迁移待验收。

原生账号切换增加同步静默租约和本地flush，旧作用域激活/清理按序串行、新账号读取前清空原生活动范围，原生失败重试等待者隔离。模拟IPC与云端回归通过，不代表实际macOS/Windows/Android安装包或真实账号验收。

## 8. 最终正确性与真实旧工作线程演练（基线c144271）
