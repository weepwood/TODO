## 产品收口
- 分类堆叠与时间分布并列布局，窄屏纵向；单日横向分类占比、多日纵向堆叠、未知合计不写零，小时未知提示一致。紧凑排行及日期工具栏；移动批量搜索独占行，截图实际检查并修正宽度；仍沿用现有 Module Card、令牌和组件，无新增依赖。
- 主体检索、仅未分类、选中当前显示结果（最多100项）、批量分类及任务关联。批量操作独立字段默认保持原值，显式选择解除才清除；全批校验后发布，不部分提交；500条映射/24分类原上限不变。提交成功清空选区，防止筛选后隐藏选择残留。无效分类草稿保存禁用，图表保留最近有效规则而非退回初始配置。
- 单日查询区间时间预算：计划块与专注分别在查询范围内取并集，跨任务重叠不重复计入；显示查询、规划占用、未规划区间、已记专注、已识别应用、未覆盖。未规划不等于工作容量，指标彼此可重叠，不能相加。仍保留任务预计/规划/专注/匹配差，不自动修改任务。回顾返回活动页保留来源日期但重新连接/授权，不复制报告到回顾或持久快照。
- 桌面主窗口暂停事件清理报告、连接和网页授权，同时使未完成查询的结果失效、停止后续分段；已经发出的请求仍可能执行到超时。报告离开页面销毁，显式保存的本机配置保留。真实锁屏、休眠不等同于此事件，未主动触发系统事件。

## 统计与隐私审查
软件与网站分别统计；同任务跨来源取区间并集，不同任务匹配不可相加。分类缺失与未知日期不自动补零；部分覆盖不当作完整工作记录。时间预算不是规划引擎的工作周容量，当前计划也不是历史计划快照。原 Rust Provider/IPC/Cargo 及冻结自研代码无差异，沿用已验证的限量、固定本机地址、显式网站授权、仅GET、不保留URL路径和窗口标题。规则 key 仅在 activitywatch-analysis.js 中定义/读写；云同步使用既有工作区 snapshot，活动报告、分类配置及分析结果不写入 data 或同步快照。显式保存配置仍是未加密 localStorage，不能把账号命名空间当作操作系统安全隔离或跨设备备份。活动历史仅内存；本轮未向真实服务请求。既有 IPC consent 是应用交互约束而非抵抗恶意本机进程的认证。
